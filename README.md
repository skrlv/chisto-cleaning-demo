# «Чисто» — демонстрационный сайт клининга

Самостоятельный проект для портфолио Сергея: адаптивный сайт вымышленной компании, калькулятор уборки, форма заявки и панель обработки заказов.

[Публичный адрес](https://skrlv.github.io/chisto-cleaning-demo/) · [Репозиторий](https://github.com/skrlv/chisto-cleaning-demo)

Публичная версия работает без серверной части. Инструкции и границы демонстрации приведены ниже.

## Запуск

Нужен Node.js 22.18 или новее. Команды выполняются из папки проекта.

```sh
npm ci
npm run dev
```

Откройте [локальный сайт](http://127.0.0.1:3000/). Остановка — Ctrl+C.

## Статическая версия для GitHub Pages

```sh
npm run build:pages
npm run check:pages
npm run preview:pages
```

Предпросмотр: [http://127.0.0.1:4173/chisto-cleaning-demo/](http://127.0.0.1:4173/chisto-cleaning-demo/). Готовая публикация находится в `out/`. Сборка учитывает базовый путь репозитория; официальный GitHub Actions workflow публикует статические файлы на Pages.

## Проверки

```sh
npm run typecheck
npm test
npm run build:pages
npm run test:e2e
```

Браузерные проверки `test:e2e` используют статический экспорт и один локальный сервер. При отсутствии браузера Playwright установите Chromium командой `npx playwright install chromium`.

Отдельные проверки серверного режима:

```sh
npm run build
npm run test:e2e:server
```

Этот набор поднимает два локальных Next.js-сервера для проверки режимов демо и серверной отправки. Реальные сообщения не отправляются: используются заглушки и сценарии отсутствующей конфигурации.

## Что попробовать

1. Выбрать генеральную уборку, 50 м², два окна и духовку: итог — **8 800 ₽**.
2. Нажать «Заполнить демо-пример», выбрать желаемую дату и сохранить заявку.
3. Открыть демо-кабинет, поменять статус, обновить страницу и проверить сохранение.
4. Отфильтровать заявки по статусу и попробовать очистку с подтверждением.

## Границы демонстрации

Все тарифы условные. Заявки сохраняются только в `localStorage` текущего браузера; компания их не получает. Используйте вымышленные контакты. Желаемая дата не бронирует время. Кабинет не имеет авторизации и не является защищённой рабочей системой. Данные можно удалить в кабинете или настройках браузера.

Формула: `max(3 000 ₽, площадь × тариф) + окна × 500 ₽ + холодильник 700 ₽ + духовка 800 ₽`. Диапазон площади — 20–300 м², окон — 0–20. Тарифы и ограничения: `lib/tariffs.ts`.

Дополнительный серверный адаптер сохранён в `server/` и `app/api/`. Он не подключён к Telegram, ключи не включены, успешная реальная отправка не заявляется. GitHub Pages не выполняет этот код, серверного API в статической публикации нет. Для реального сервиса потребуются отдельный сервер, защищённое хранение, авторизация и настройка интеграции.
